# AfriConnect Summit – Site Vitrine d'une Conférence Tech Panafricaine

## Description

AfriConnect Summit est un site web vitrine conçu dans le cadre d'un projet académique. Il met en avant une conférence technologique panafricaine fictive réunissant des développeurs, des entrepreneurs, des investisseurs et des étudiants issus de tout le continent africain.

Le projet a été développé en respectant les standards modernes du web en 2026 : design minimaliste, animations sobres, mode sombre, navigation fluide et expérience utilisateur optimisée sur tous les appareils.

## Objectifs du projet

* Concevoir une interface moderne et intuitive.
* Développer un site entièrement responsive.
* Mettre en œuvre une navigation simple et fluide.
* Intégrer un mode sombre (Dark Mode).
* Ajouter des animations légères pour améliorer l'expérience utilisateur.
* Respecter les bonnes pratiques de développement web.

## Fonctionnalités

* Page d'accueil immersive avec une section Hero.
* Barre de navigation responsive.
* Présentation de la conférence.
* Programme détaillé des activités.
* Présentation des intervenants.
* Affichage des différents niveaux de sponsors (Or, Argent et Bronze).
* Statistiques animées.
* Formulaire de contact avec validation JavaScript.
* Bouton « Retour en haut ».
* Mode sombre avec sauvegarde des préférences utilisateur.
* Animations au défilement (Scroll Animations).

1. Cloner le dépôt Git :

```bash

```

2. Accéder au dossier du projet :

```bash
D:\Bureau\coursHTML\ZOUNGRANA-Maureen-AfriConnectSummit
```

3. Ouvrir le fichier `index.html` dans un navigateur ou utiliser l'extension Live Server sur Visual Studio Code.
